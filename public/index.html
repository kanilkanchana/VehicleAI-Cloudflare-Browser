UNDER THE HOOD

From a frame to an insight.

Real pretrained computer vision, with tracking and counting logic. These are the actual steps—not simulated detections.

01

Read a real frame

The video element provides current pixels from your chosen file or camera.

02

Run pretrained YOLO

An ONNX model predicts boxes, classes and confidence for road vehicles.

03

Associate tracks

Nearby matching boxes keep the same temporary vehicle ID across sampled frames.

04

Detect line crossings

When a tracked center moves across the horizontal line, the count increases. We stabilize labels using multiple observations, not one guess.

05

Inspect the results

See annotations, vehicle breakdown, crossing direction and exportable counts.

Want to learn the machine learning pipeline?

The developer Jupyter notebook includes class-confusion analysis and runnable Python examples: loading a real video frame, exporting YOLO to ONNX, tracking, counting and validation. The public website explains the concepts without publishing copyable code snippets.
